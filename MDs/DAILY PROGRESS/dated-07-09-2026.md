## 1. Issues Investigated

### DJI RS 2 Remote RTMP Streaming Failed in the Field

**User Report:**
- Tested live RTMP streaming from field using DJI RS 2 remote controller at 720p.
- After clicking "Live Streaming", countdown "3, 2, 1" completed.
- 3–4 seconds later, received an error notification on the remote: "RTMP streaming failed".
- Challenge: Drone and remote are only available during field operations, making live desktop debugging impossible without persistent diagnostics.

**Investigated Probable Causes:**
1. **Stream Key / URL Configuration Mismatch:** DJI GO 4 / RS 2 remote might be configured with an outdated path (`/ingest/` vs `/live/`), a mistyped 5-digit stream key, or an inactive stream key in SQLite DB.
2. **Auth Webhook Rejection (`401` or `403`):** MediaMTX calls `http://server:5011/api/hooks/auth` on every publish. If key lookup fails or IP filter fails, MediaMTX drops the drone immediately.
3. **Network / LTE Carrier Block (Port 1935):** If mobile network or SIM card blocks outbound TCP port 1935, the 3–4 second countdown expires with timeout without ever reaching Server 0149.
4. **MediaMTX Logs Ephemeral:** Without persistent file logging, past connection attempts in Docker are lost when inspecting after the fact.

## 2. Implementation: Persistent Field Diagnostics Logging System

1. **MediaMTX Verbose Debug Logging:** Set `logLevel: debug` and `logDestinations: [stdout]` in `mediamtx.yml` to capture full RTMP handshake and connection details.
2. **Persistent Logs Volume Mount:** Configured `./logs:/app/logs` in `docker-compose.yml` for persistent disk storage across container restarts.
3. **Dedicated Field Logger (`fieldLogger.ts`):** Structured append-only logging for auth requests, recording all details (timestamp, action, raw path, sanitized key, client IP, raw payload, result, reason).
4. **Enhanced Auth Hook Diagnostics:** Log every incoming webhook request, including internal IP validation results and DB query outcomes.
5. **Dashboard Diagnostics View / API:** Provide administrative access to view recent field connection logs directly from the web interface or log files.
