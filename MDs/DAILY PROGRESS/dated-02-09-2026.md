## 2. Actions & Investigations

### A. "Origin not allowed" Investigation
- **Root Cause:** In `rtmp-streamer/server/src/index.ts`, CORS whitelist defaults to `["http://localhost:3000", "http://localhost:5173"]`. `ALLOWED_ORIGINS` was not passed through `docker-compose.yml`, so requests with origin `http://100.118.109.5:3000` or the public domain were rejected by Express with `403 Forbidden: Origin not allowed`.
- **Resolution:** Added `ALLOWED_ORIGINS` to `.env` and `docker-compose.yml`, dynamic origin support for configured domain, and updated `mediamtx.yml` allowed origins.

### B. WAN Port Allocation Strategy
- Existing port 80 and 443 are currently mapped to `172.16.3.39`.
- New ports assigned for Server 0149 (`172.16.3.50`):
  - **RTMP Ingest:** Port `1935` (WAN `1935` → LAN `172.16.3.50:1935`)
  - **Web Dashboard & API:** Port `8443` (WAN `8443` → LAN `172.16.3.50:3000` or Caddy)
  - **WebRTC Signaling/Media:** Port `8889` (WAN `8889` → LAN `172.16.3.50:8889` TCP/UDP)
